## Риски

- **Настройки**: settings.json Soroka должен подхватываться без порчи —
  читать с осторожностью, писать только в свои ключи.
- **GigaChat**: ключ/доступность API — при сбое AI-функции деградируют
  мягко (без блокировки почты).
- **Темы**: системные контролы красятся ограниченно — owner-draw только
  там, где реально нужно (правило KISS из PLAN.md).
- **Реальные данные**: проверка только на тестовых ящиках
  (reznikov_a@mail.ru ↔ russiaimperia@yandex.ru), живым адресатам
  без разрешения владельца не писать.
