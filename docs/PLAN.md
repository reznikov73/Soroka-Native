# План миграции: Soroka (Tauri + WebView2) → POS Mail Native (Win32)

Дата: 2026-11-18. Владелец утвердил переход после четырёх неудачных итераций
борьбы с медленным ресайзом (TASK-099 → 102/103 → 104 → 105 → 106 → 107 → 108).

## Диагноз (зачем переезд)

- TASK-105: нативный ресайз с дросселем — стало хуже.
- TASK-106: откат + CSS-заморозка — не помогло.
- TASK-107: полностью системные окна, в цикле ресайза ноль нашего кода —
  рамка летает, содержимое отстаёт.
- Вывод: узкое место — перестройка DOM внутри WebView2 на каждый шаг жеста.
  Это ограничение движка, а не кода приложения. Нативная оболочка его не имеет.

## Целевая архитектура

- Оболочка (окна, дерево папок, список писем, тулбар, редактор, диалоги,
  трей) — чистый Win32 через `windows-rs`. Список писем — виртуальный
  `ListView` (`LVS_OWNERDATA`): 100 000 строк без лагов, данные отдаются по
  `LVN_GETDISPINFO`. Рисование — GDI/GPU, системная рамка, Aero Snap.
- Тело HTML-письма — WebView2 (`webview2-com`), встроенный только в панель
  просмотра. Он не участвует в раскладке окна и не влияет на скорость
  ресайза (обновляется bounds'ом, перерисовка — после жеста).
- Всё хозяйство почты — существующий Rust-код из Soroka, без изменений
  логики: только замена транспортного слоя `#[tauri::command]` на вызовы
  из оконного кода.

### Переписывается (≈12 300 строк TS/CSS/HTML → нативная оболочка)

## Риски и ответы

- **HTML-письма** → уже решено: WebView2 в панели просмотра, изолирован от
  раскладки окна (проверяется шипом Фазы 0).
- **Сложный редактор письма** (форматирование, вложения) → RichEdit +
  диалоги; при нехватке возможностей — WebView2 в отдельном окне редактора
  (как в The Bat!): скорость списка это не трогает.
- **Объём работы** → ядро (10k строк) не трогаем, переписываем только
  оболочку; шип снижает архитектурный риск до нуля.

## Правила

- Одна задача — один коммит — один документ `docs/TASK-NXX-*.md` (как в Soroka).
- Версии: до первого релиза `0.1.x`.
- KISS: системные контролы как есть; кастомная отрисовка только там, где
  реально нужна (строки списка с флажками/звёздами, темы).
