# TASK-N05 — Фаза 2, срез 3: темы (тёмная/светлая) и русские даты

Дата: 2026-11-18. Версия: 0.3.3. Предыдущая задача: TASK-N04
(v0.3.2 — сплиттеры панелей).

## Постановка

ROADMAP N05: палитра Soroka (тёмная/светлая) для оболочки — дерево,
список, статус-бар, сплиттеры, панель письма (owner-draw там, где
системные контроли не красятся); переключение темы; русские даты
(«сегодня, 14:32», «вчера», «12 ноября») в списке и шапке письма.
Критерий приёмки: оболочка и панель выглядят единообразно в обеих
темах; даты читаются по-русски. Схема окна не меняется: список
остаётся виртуальным, DOM в кадре ресайза по-прежнему нет.

## Решения

### Палитры

- **Тёмная** — дословно переменные `:root` из `src/styles.css` Soroka:
  accent `#8b83ff`, bg-app `rgb(28,30,36)`, text `rgba(255,255,255,.92)`,
  text2 `.62`, stroke `.095`, panel `.035` поверх фона. Полупрозрачные
  значения сведены к сплошным поверх bg-app (GDI альфы не умеет):
  text → `#EDEDEE`, text2 → `#A9AAAC`, stroke → `#323339`.
- **Светлой темы в Soroka нет** (`color-scheme: dark`, настроек темы в
  settings.rs тоже нет — проверено). Светлая собрана комплементарно в той
  же структуре (акцент `#5b50d9` — затемнённый акцент Soroka для белого
  фона); когда светлая тема появится в Soroka — значения заменить.
- Дефолт — тёмная (как в Soroka). Хранение — `layout.json` (наш файл,
  поле `theme: "dark"|"light"`, serde-default для старых файлов без
  поля; срез N09 перенесёт тему в общий settings.json). Заодно закрыт
  мелкий долг: Cargo `description` обновлён с «срез 1» на актуальный.

### Оболочка (что чем красится)

- **Дерево**: TVM_SETBKCOLOR / TVM_SETTEXTCOLOR / TVM_SETLINECOLOR.
- **Список**: LVM_SETBKCOLOR / LVM_SETTEXTCOLOR / LVM_SETTEXTBKCOLOR +
  custom draw (каждый ITEMPREPAINT/сабайтем): колонка даты — text_dim,
  остальное — text; непрочитанные — полужирный (как раньше).
- **Выделение строки** — системное (синий + белый), у дерева и списка
  одинаково: контрол красит его сам, палитру в выделение не вмешиваем
  (KISS; owner-draw выделения — N10, если понадобится).
- **Статус-бар**: msctls_statusbar32 не даёт цвет текста — вместо него
  собственное окно класса `SorokaNativeStatus` (фон, верхняя линия
  stroke, текст text_dim, шрифт AppState; текст — через
  SetWindowTextW/GetWindowTextW). `status_text()` не изменился по
  сигнатуре.
- **Сплиттеры**: фон — bg, полоса-хвата — stroke, при наведении/жесте —
  accent (долг TASK-N04 «подсветка системными цветами» закрыт).
- **Поле поиска**: WM_CTLCOLOREDIT (SetTextColor/SetBkColor + кисть
  из AppState, пересоздаётся при смене темы). Рамка WS_EX_CLIENTEDGE
  осталась системной — выравнивание с палитрой в N10.
- **Фон главного окна**: WM_ERASEBKGND палитрой (щели вокруг поля
  поиска, ресайз до переложения детей).
- **Панель письма**: шаблон letter_html/loading_html/empty_pane_html
  берёт hex-цвета из палитры (замена светлой заглушке v0.3.2).
- **Переключение**: меню «Вид → Тёмная тема» (галочка CheckMenuItem),
  apply_theme() до ShowWindow при старте (без вспышки системных
  цветов). Панель письма пере-навигируется из pane_body — бэкенд не
  трогаем; для этого PaneBody теперь хранит вложения и признак обрезки.

### Русские даты (src/dates.rs, без новых зависимостей)

- `parse_rfc5322` — практическое подмножество RFC 5322: [DoW,] DD Mon
  YYYY HH:MM[:SS] ±ZZZZ + именованные зоны (GMT/UT/UTC/MSK/EST…).
  Ядро хранит `MessageHeader.date` сырой строкой ENVELOPE (в тестах
  ядра: «Mon, 19 Oct 2026 10:00:00 +0300»). Не разобралось — None,
  вызывающий показывает сырую строку.
- Календарная математика — алгоритм Хиннанта (days_from_civil /
  civil_from_days), пролептический григорианский, с тестами на
  високосности (2024/2000 да, 2025/2100 нет).
- Локальное «сейчас» и смещение зоны — GetLocalTime/GetSystemTime
  (windows 0.62 отдают SYSTEMTIME по значению; добавлена фича
  Win32_System_SystemInformation — тот же крейт, версии не менялись).
- Список: «сегодня, 14:32» / «вчера» / «12 ноября» (текущий год) /
  «12 ноября 2025». Шапка письма: «сегодня, 14:32» / «вчера, 09:10» /
  «18 ноября 2026, 14:32». Дата в цитате ответа — по-прежнему сырая
  строка заголовка (как в традиционных клиентах).
