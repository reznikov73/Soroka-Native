# TASK-N11 — календарь: сетка месяца, события дня, экспорт в .ics

Дата: 2026-11-23. Версия: 0.3.19. Срез Фазы 3 из `docs/ROADMAP.md`.
Начало работы — z.ai (`src/ics.rs`, `src/calendar.rs`, но без подключения к
оболочке и без коммита); подключение, сборка, правки и живая проверка —
AutoClaw на машине владельца.

## Постановка

Срез N11 по ROADMAP: перенести ядро `src-tauri/src/ics.rs` Soroka (события
~200 строк), сделать панель календаря и приглашения `.ics` из писем.
`src/mail/` не правится — данные берутся из готового ядра
(`Store::{load_calendar_events, add_calendar_event, delete_calendar_event}`).

## Решения

**Окно календаря** (`SorokaCalendarWnd`, `src/calendar.rs`): своя отрисовка
сетки GDI — 7 колонок × 6 строк, дни другого месяца приглушены, сегодняшний
день акцентом, выбранный — фоном выделения; в клетке дня выводится время и
тема первого события (с многоточием). Шапка: `‹` / `›` (месяцы),
«Сегодня», рядом — статус «Ноябрь 2026 — событий в месяце: N, в дне: M».
Панель справа: список событий дня + «Добавить событие…» / «Удалить» /
«В файл .ics».

**Карточка события** (`SorokaEventWnd`): Название, Дата (`ГГГГ-ММ-ДД`),
Время (`ЧЧ:ММ`, пусто — событие на весь день), Описание; «Сохранить» →
`Store::add_calendar_event`, «Отмена»/крестик — закрыть. Ввод даты и времени
проверяется до записи (`valid_date`/`valid_time`).

**Экспорт** — перенесённый `ics.rs` (дословно из Soroka; отличие одно: `uid`
из крейта `uuid`, добавленного в зависимости): событие сохраняется в
«Загрузки» (`%USERPROFILE%\Downloads`), путь показывается сообщением.
Импорт `.ics` из писем в этот срез не входил (см. «Осталось»).

**Подключение к оболочке** (это и было главным пробелом): `mod calendar;`,
`hwnd_calendar` в `AppState`, пункт меню «Почта → Календарь…»
(`IDM_CALENDAR = 136`), обработчик `WM_COMMAND`, снятие HWND по
`WM_APP_CALENDAR_CLOSED`, окно добавлено в рассылку смены темы.

**Даты** — в `dates.rs` добавлен `month_nom_ru` (именительный падеж для
заголовка: «Ноябрь»); форматирование в списках осталось на родительном.

**Тема** — окно календаря красится палитрой: фон, сетка, клетки, панель;
для статуса и списка добавлен `WM_CTLCOLORSTATIC/EDIT/LISTBOX` (без него
comctl32 оставляет их белыми в тёмной теме).

### Правки при сборке (код ни разу не компилировался)

`calendar.rs` был написан «на бумаге»: 28 ошибок компиляции. Все правки —
сигнатуры/импорты, архитектура не менялась:

| Что | Правка |
|---|---|
| `LB_*`/`LBS_NOTIFY` импортированы из `UI::Controls` | они в `WindowsAndMessaging` |
| `WM_CTLCOLORSTATIC`/`EDIT` не в области видимости | стали *binding*-паттернами и глотали ветки `match` — импортированы (та же болезнь, что в TASK-N12) |
| `windows::Win32::System::Time` | добавлена фича `Win32_System_Time` |
| `GetParent` возвращает `Result<HWND>` | `.unwrap_or_default()` |
| в `CalState` нет `hwnd_btn_add/del/ics` | поля добавлены и инициализированы |
| `DefWindowProcW`, `SetBkColor` не импортированы | импортированы |
| `dates::month_nom_ru` отсутствует | добавлен в `dates.rs` |

### Дефекты, найденные живой проверкой

1. **Статус перекрывал кнопки шапки**: `layout()` ставил его в (12, 22), а
   кнопки `‹ › Сегодня` стоят в (12…190, 10…38) — текст обрезался, кнопки
   были полузакрыты. Статус перенесён правее кнопок (200, 12).
2. **Белые статус и список в тёмной теме** — добавлен `WM_CTLCOLOR*`
   (см. выше), панель стала тёмной.

## Осталось

- **Приглашения `.ics` из писем** (вторая половина среза N11 по ROADMAP):
  вложение-приглашение в шапке письма → «Добавить в календарь». Сейчас
  календарь умеет только экспорт.
- Живая приёмка владельцем: события из его реальной базы Soroka
  (`%APPDATA%\Soroka\soroka.db`, таблица `calendar_events` общая).
- Открытие `.ics` двойным щелчком (ассоциация файла) — вне объёма, как в Soroka.
