# POS Mail Native

Нативный почтовый клиент для Windows: оболочка на чистом Win32 (Rust, `windows-rs`), HTML-движок (WebView2) — только для тела письма.

Это перерождение [Soroka / POS Mail](https://github.com/reznikov73/Soroka). Причина переезда — диагноз, подтверждённый четырьмя итерациями (TASK-099…108): в приложении на WebView2 системная рамка летает за курсором, а содержимое отстаёт — стоимость перестройки DOM нельзя убрать ниже определённого предела, пока вебвью виден во время жеста. Нативная оболочка этого предела не имеет.

**Статус: Фаза 1 — почтовый каркас.** Реальные ящики, папки и письма: IMAP-синхронизация, чтение (тело — WebView2), написание/ответ/пересылка, вложения в обе стороны, отправка SMTP, очередь исходящих. База и настройки общие с Soroka (`%APPDATA%\Soroka`).

## Сборка

Нужны: Rust (stable, target `x86_64-pc-windows-msvc`), VS Build Tools, установленный Evergreen WebView2 Runtime (есть в Windows 10/11 по умолчанию).

```
cargo run --release
```

## Что умеет Фаза 1

1. Ящики: `Ящики → Добавить ящик` (email, пароль, IMAP/SMTP; кнопка «Проверить соединение»). Ящики, настроенные в Soroka, подхватываются сами — файл `accounts.json` общий.
2. Дерево папок по ящикам (кэш SQLite + обновление при синхронизации INBOX). Выбор папки — мгновенный показ писем из кэша.
3. Список писем — виртуальный ListView (как Фаза 0, любые объёмы), непрочитанные — полужирным, маркер вложений.
4. Чтение: выбор письма — тело грузится кэш → сеть, прочитанным помечается на сервере. HTML-письма — санитизация ammonia (из ядра Soroka), как раньше.
5. Вложения: клик по имени в шапке письма — файл сохраняется в «Загрузки». Вложения при написании — мультивыбор файлов.
6. Написание/ответ/пересылка — отдельное окно (Ctrl+N / Ctrl+R / Ctrl+Shift+R / Ctrl+F), отправка SMTP, копия в «Отправленные», без сети — письмо в очередь (TASK-089) и уходит при следующей синхронизации.
7. Удаление (Del) — в корзину сервера; прочитано/не прочитано (Ctrl+U); синхронизация папки (F5).

Ресайз окна — по-прежнему чистый Win32: список переложится мгновенно при любом объёме, WebView2 в кадре жеста не участвует.

## Структура

- `src/main.rs` — окно, раскладка, меню, диспетчер сообщений; WebView2-панель.
- `src/ui.rs` — дерево папок, виртуальный список, шаблон панели письма, события бэкенда.
- `src/backend.rs` — рабочий поток почты: задачи (синхронизация/тело/отправка/вложения) и события в UI (порт команд Soroka).
- `src/compose.rs` — окно написания письма; `src/account_dlg.rs` — окно ящика.
- `src/mail/` — почтовое ядро Soroka, перенесено без изменений (IMAP, SMTP, SQLite-кэш, разбор MIME, контакты).
- `docs/PLAN.md` — план миграции: что переносится, что переписывается, этапы.
- `docs/WORKFLOW.md` — правила работы агента над этим репозиторием.
