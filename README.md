# POS Mail Native

Нативный почтовый клиент для Windows: оболочка на чистом Win32 (Rust, `windows-rs`), HTML-движок (WebView2) — только для тела письма.

Это перерождение [Soroka / POS Mail](https://github.com/reznikov73/Soroka). Причина переезда — диагноз, подтверждённый четырьмя итерациями (TASK-099…108): в приложении на WebView2 системная рамка летает за курсором, а содержимое отстаёт — стоимость перестройки DOM нельзя убрать ниже определённого предела, пока вебвью виден во время жеста. Нативная оболочка этого предела не имеет.

**Статус: Фаза 0 — шип скорости.** Одно окно: дерево папок, виртуальный список на 50 000 «писем», панель письма на WebView2, статус-бар. Кода ~500 строк, весь — доказательство концепта.

## Сборка

Нужны: Rust (stable, target `x86_64-pc-windows-msvc`), VS Build Tools, установленный Evergreen WebView2 Runtime (есть в Windows 10/11 по умолчанию).

```
cargo run --release
```

## Что проверить в шипе

1. Тянуть край/угол окна: список переложится мгновенно, отставания быть не должно — при 50 000 строк.
2. Двойной клик по строке — «письмо» открывается в правой панели (WebView2).
3. Aero Snap, `Win+стрелки`, максимизация — обычное поведение Windows.

Если всё три пункта ок — архитектура подтверждена, дальше Фазы (см. `docs/PLAN.md`).

## Структура

- `src/main.rs` — шип: окно, раскладка, виртуальный список, дерево, WebView2-панель.
- `docs/PLAN.md` — план миграции из Soroka: что переносится, что переписывается, этапы.
- `docs/WORKFLOW.md` — правила работы агента над этим репозиторием.

## Данные

Формат хранения будет тем же, что у Soroka (SQLite + FTS5 в `%APPDATA%\Soroka`) — базу можно будет открыть напрямую, без экспорта/импорта.
