# POS Mail Native

Нативный почтовый клиент для Windows: оболочка на чистом Win32 (Rust, `windows-rs`), HTML-движок (WebView2) — только для тела письма.

Это перерождение [Soroka / POS Mail](https://github.com/reznikov73/Soroka). Причина переезда — диагноз, подтверждённый четырьмя итерациями (TASK-099…108): в приложении на WebView2 системная рамка летает за курсором, а содержимое отстаёт — стоимость перестройки DOM нельзя убрать ниже определённого предела, пока вебвью виден во время жеста. Нативная оболочка этого предела не имеет.

**Статус: Фаза 2 — паритет ядра (в работе).** Фаза 1 (почтовый каркас) готова: реальные ящики, папки и письма: IMAP-синхронизация, чтение (тело — WebView2), написание/ответ/пересылка, вложения в обе стороны, отправка SMTP, очередь исходящих. База и настройки общие с Soroka (`%APPDATA%\Soroka`). Фаза 2 начата с поиска (TASK-N03).

## Сборка

Нужны: Rust (stable, target `x86_64-pc-windows-msvc`), VS Build Tools, установленный Evergreen WebView2 Runtime (есть в Windows 10/11 по умолчанию).

```
cargo run --release
```

## Что умеет

1. Ящики: `Ящики → Добавить ящик` (email, пароль, IMAP/SMTP; кнопка «Проверить соединение»). Ящики, настроенные в Soroka, подхватываются сами — файл `accounts.json` общий.
2. Дерево папок по ящикам (кэш SQLite + обновление при синхронизации INBOX). Выбор папки — мгновенный показ писем из кэша.
3. Список писем — виртуальный ListView (как Фаза 0, любые объёмы), непрочитанные — полужирным, маркер вложений.
4. Чтение: выбор письма — тело грузится кэш → сеть, прочитанным помечается на сервере. HTML-письма — санитизация ammonia (из ядра Soroka), как раньше.
5. Вложения: клик по имени в шапке письма — файл сохраняется в «Загрузки». Вложения при написании — мультивыбор файлов.
6. Написание/ответ/пересылка — отдельное окно (Ctrl+N / Ctrl+R / Ctrl+Shift+R / Ctrl+F), отправка SMTP, копия в «Отправленные», без сети — письмо в очередь (TASK-089) и уходит при следующей синхронизации.
7. Удаление (Del) — в корзину сервера; прочитано/не прочитано (Ctrl+U); синхронизация папки (F5).
8. Поиск по всем папкам ящика («/», как в Soroka, или `Папка → Найти в ящике`): FTS5-индекс из ядра Soroka — регистр и кириллица, слова как префиксы, `ivan@mail.ru` находится по частям. Живой ввод (пауза 300 мс) или Enter; Esc — вернуться к папке. Колонка «Папка» показывает, где лежит письмо; клик по строке открывает письмо и делает его папку текущей (ответ/удаление работают сразу). Статус показывает число совпадений и сколько из них — только в теле письма.
9. Сплиттеры панелей (TASK-N04): границы «дерево|список» и «список|тело» тянутся мышью (минимум панели 110px), двойной клик — сброс пары к дефолту; веса сохраняются в `%APPDATA%\Soroka\layout.json` и переживают перезапуск.
10. Темы и русские даты (TASK-N05): тёмная (палитра Soroka из styles.css, дефолт) и светлая — `Вид → Тёмная тема`; с TASK-N09 выбор хранится в общем settings.json (`native_theme`). Красятся дерево, список (дата — вторичным цветом, непрочитанные — полужирным), собственный статус-бар, сплиттеры (хват — акцент при наведении), поле поиска и панель письма. Даты в списке: «сегодня, 14:32», «вчера», «12 ноября», «12 ноября 2025»; в шапке письма — полный формат «18 ноября 2026, 14:32». Что не разобралось — сырая строка заголовка.
11. Геометрия окон (TASK-N06): размер/позиция/развёрнутость главного окна и окон написания/ящика сохраняются при закрытии и восстанавливаются при запуске — всё в том же layout.json вместе с весами сплиттеров (единый стейт компоновки). Снятая с развёрнутого окна нормальная позиция возвращается при «восстановить»; окно не улетает за экран при смене мониторов (зажим по виртуальному рабочему столу).
12. Настройки (TASK-N09): `Файл → Настройки...` — тема (тёмная/светлая), минимизация в трей, уведомления, автозапуск, интервал автопроверки (для трея, N07) и ключ GigaChat (для ИИ Фазы 3). Хранится в общем с Soroka `%APPDATA%\Soroka\settings.json` — читаем всё, пишем только свои ключи (`native_theme`, `native_autosync_min`) и поля `ui.*` поверх прочитанного файла (read-modify-write): категории, промпты и подписи Soroka не теряются. Тема переехала сюда из layout.json (одноразовая миграция при старте); ключ GigaChat — в `gigachat.json` как в Soroka (env-ключ имеет приоритет). Смена темы в диалоге применяется сразу, без перезапуска.
13. Трей и автопроверка (TASK-N07): иконка в области уведомлений (конверт Сороки; при непрочитанных — с точкой, подпись «POS Mail — N непрочитанных…»), меню правой кнопки — Открыть / Проверить почту / Выход; клик левой — показать окно. Кнопка «—» и крестик прячут окно в трей (если `ui.minimize_to_tray`; подсказка при первом сворачивании), выход — через меню трея. Автопроверка — таймером раз в N минут (`native_autosync_min`, 0 — выкл.), синхронизирует INBOX всех ящиков как F5. Новые письма — balloon-уведомление Windows («Новое письмо / N новых…», «От кого: Тема») когда включены `ui.notifications` и окно не на виду; считается по новым UID против прошлого снимка кэша (не «все загруженные»). Автозапуск — реестр `HKCU\...\Run`, значение `SorokaNative`. Иконка окна/панели задач — app.ico Сороки.

Ресайз окна — по-прежнему чистый Win32: список переложится мгновенно при любом объёме, WebView2 в кадре жеста не участвует.

## Структура

- `src/main.rs` — окно, раскладка, меню, диспетчер сообщений; WebView2-панель.
- `src/ui.rs` — дерево папок, виртуальный список, шаблон панели письма, события бэкенда, статус-бар, применение темы.
- `src/theme.rs` — палитры Soroka (тёмная/светлая) для оболочки и панели письма (TASK-N05).
- `src/dates.rs` — русские даты: разбор RFC 5322 без зависимостей, «сегодня/вчера/12 ноября» (TASK-N05).
- `src/settings.rs` — общий с Soroka settings.json: дословный порт ядра настроек (TASK-020) + наши ключи read-modify-write (TASK-N09).
- `src/settings_dlg.rs` — окно настроек (TASK-N09).
- `src/tray.rs` — иконка трея, меню, balloon-уведомления (TASK-N07); `src/ico.rs` — разбор .ico (чистый, тестируется на Linux); `src/notify.rs` — тексты трея/уведомлений и подсчёт новых писем; `src/autostart.rs` — автозапуск (реестр HKCU Run); `src/icons/` — иконки из Soroka (app/tray/tray-alert, сконвертированы в .ico).
- `src/backend.rs` — рабочий поток почты: задачи (синхронизация/тело/отправка/вложения) и события в UI (порт команд Soroka).
- `src/compose.rs` — окно написания письма; `src/account_dlg.rs` — окно ящика.
- `src/mail/` — почтовое ядро Soroka, перенесено без изменений (IMAP, SMTP, SQLite-кэш, разбор MIME, контакты).
- `docs/PLAN.md` — план миграции: что переносится, что переписывается, этапы.
- `docs/ROADMAP.md` — дорожная карта срезов после v0.3.2 (N05–N15, Фазы 2–3).
- `docs/WORKFLOW.md` — правила работы агента над этим репозиторием.
